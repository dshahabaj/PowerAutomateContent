Azure DevOps Auto Task Creation

Power Automate | SharePoint | DevOps

Turn every SharePoint item into a tracked DevOps work item — automatically.

What you'll learn today:
  • The full flow: SharePoint → Power Automate → DevOps → Email
  • Which connectors are needed
  • Field mapping between SharePoint and DevOps
  • How to send email notifications
  • Error handling and best practices
01

The Problem

Your team uses SharePoint for requests. Your developers use Azure DevOps for tasks. Nothing connects them.

  • Someone adds an item to SharePoint
  • Someone else manually creates a DevOps task
  • Someone forgets — and the task is lost
Manual task creation is slow, error-prone, and easy to forget.
02

The Solution

One Power Automate flow that does three things:

Watch SharePoint
Create DevOps Task
Send Email
Zero manual steps. Every request becomes a tracked work item.
03

The Full Workflow

Here's how the flow runs, step by step:

Flow Chart

flowchart TD
    A[SharePoint Item Created] --> B[Power Automate Trigger]
    B --> C[Get Item Details]
    C --> D{Is Priority Set?}
    D -->|Yes| E[Create Azure DevOps Work Item]
    D -->|No| F[Set Default Priority]
    F --> E
    E --> G[Get Work Item URL]
    G --> H[Send Email Notification]
    H --> I[Update SharePoint Status]
    I --> J[End]
    E -->|Error| K[Log Error to SharePoint]
Each step has one job. Keep it simple. Keep it readable.
04

The SharePoint List

This is the list that triggers the flow. Every time a new item is added, Power Automate wakes up.

Screenshot

Figure 1: SharePoint list used as the trigger source. Columns: Title, Description, Priority, Assigned To, Due Date.

Key Columns

  • Title — becomes the DevOps work item title
  • Description — maps to the DevOps description field
  • Priority — determines work item type or priority
  • Assigned To — the person who will own the task
  • Due Date — sets the target completion date

06

Field Mapping

Every SharePoint field maps to a DevOps field. Here's the mapping we use:

SharePoint
  • Title
  • Description
  • Priority
  • Assigned To
  • Due Date
Azure DevOps
  • Title
  • Description
  • Priority
  • Assigned To
  • Target Date
Use dynamic content to pull values from SharePoint and drop them into DevOps fields. No manual typing.
07

Connectors You Need

  • SharePoint — to trigger and read items
  • Azure DevOps — to create work items
  • Office 365 Outlook — to send email notifications
  • Microsoft Teams (optional) — for channel alerts
Azure DevOps is a premium connector. You'll need a Power Automate Premium license or a Per-Flow plan.
