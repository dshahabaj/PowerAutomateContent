What is a Connection Reference?

A reusable pointer that tells your flow which connection to use — without hardcoding credentials into the flow logic.

Build the flow once. Map the credentials per environment. No code changes.

02

Connector vs Connection vs Reference

Connector

The service interface. SharePoint, Outlook, SQL, Dataverse.

Connection

The authenticated instance. Credentials or service principal.

Connection Reference A reusable pointer that tells the flow which connection to use in a given environment.
Connector = capability. Connection = authentication. Reference = portability.
03

Why It Matters in Real Projects

Dev uses a developer account. Test uses a service account. Production uses a secured enterprise identity.

Without a Connection Reference The flow is tied to one user. Deployment breaks. Tokens expire. Reports fail silently.
Connection References separate logic from credentials. Same solution. Different environment. Zero rework.
  • Reduced deployment failures
  • Centralized administration
  • Cleaner governance and audits

07

Deployment & ALM Process

Typical flow
  1. Build flow in Development
  2. Add connector + connection reference in Solution
  3. Export managed or unmanaged solution
  4. Import to Test / UAT
  5. Admin maps the correct connection
  6. Validate and promote
Critical for CI/CD. Without references, every deployment needs manual reconfiguration.
08

Security & Governance

  • Never use personal accounts for production automation
  • Use service accounts with least privilege
  • Review ownership of connection references regularly
  • Align policies with Microsoft Entra and environment security
Connection References separate business logic from authentication. Audits become easier. Reviews become faster.
09

Best Practices & Common Mistakes

  • Use clear names like SharePoint_Prod_Reference
  • Keep flows inside a solution
  • Validate mapped connections after every deployment
  • Apply least-privilege access
  • Document who owns the reference and which environment it maps to
Common mistake Building a flow with a personal connection. Promoting the solution without updating the production mapping.
