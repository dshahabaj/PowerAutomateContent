Lesson: Compose Action
01 — What you'll learn

Compose in Power Automate

Compose is the most underrated action in Power Automate. It holds a value, an expression, or a formula — without needing a variable.

By the end

You'll know when to use Compose instead of Variables, how to chain expressions, and the mistakes that break most flows.

💡 Goal: Replace half your variables with one Compose action.
02 — What it is

A container for a value

Compose stores whatever you give it: a string, a number, a JSON object, or an expression result.

Input

Any value — text, number, formula, or dynamic content

Output

One fixed value you can reference anywhere in the flow

💡 Compose can't change. Once set, it's fixed. That's the point.
03 — Simple example

Store a calculated value

Compose input

concat('Hello, ', triggerBody()?['name'])

Compose output

"Hello, Shahabaj"

💡 One action. One value. Reusable everywhere below.
04 — Why it matters

Fewer variables, cleaner flow

  • No Initialize Variable step
  • No memory overhead
  • No scope issues inside loops
  • Easier to read in run history
💡 If the value never changes, Compose is the right tool.

06 — Expressions

Compose + expressions = power

You can put any WDL expression inside Compose. It becomes a reusable value.

Example

utcNow('yyyy-MM-dd') → today's date as a clean string

💡 Compute once. Use many times.
07 — Concatenating

Build strings step by step

Compose can combine multiple fields into one clean string:

concat(item()?['first'], ' ', item()?['last'], ' — ', item()?['email'])

💡 This is the pattern for building HTML, CSV, and email bodies.

18 — Pitfalls

Common mistakes

Tap a mistake to see why it trips beginners up.

Expecting Compose to update▼
Compose is static. If you need to change the value inside a loop, use a Variable instead.
Forgetting quotes around strings▼
In expressions, plain text needs single quotes: 'Hello', not Hello.
Using Compose when a simple field would do▼
If you're just referencing a trigger field, use dynamic content directly. Compose adds an extra step.
Nesting Compose outputs incorrectly▼
Use outputs('Compose') to reference another Compose action's result.
19 — Best practices

Write clean Compose actions

  • Rename every Compose action clearly
  • Use it for expressions you'll reference twice or more
  • Keep expressions short — split complex logic into multiple Compose actions
  • Use outputs('Compose') to chain
  • Test in run history before deploying
💡 A well-named Compose is a gift to your future self.
20 — Advanced

Chaining Compose actions
