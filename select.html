01 — What you'll learn

Select in Power Automate

Select reshapes every item in an array — in one action, with no loop.

By the end

You'll know what Select does, how to reshape arrays, how it compares to Filter Array, and how to avoid the mistakes most beginners make.

💡 Goal: Replace slow Apply to Each loops with one clean Select action.
02 — What it is

Change the shape, not the count

Select takes an array and gives each item a new shape — smaller, renamed, or combined fields.

Input

Array of items with many fields

Output

Same count, fewer fields per item

💡 Takeaway: Select reshapes. The number of items never changes.
03 — Simple example

From 5 fields to 2

Before — 5 fields each

  • Readable outputs in run history
  • Great for building CSV or HTML tables
💡 Select is how you send clean data to the next step.

18 — Pitfalls

Common mistakes

Tap a mistake to see why it trips beginners up.

Confusing Select with Filter Array▼
Select keeps every item — it only changes the shape. Filter Array removes items.
Forgetting the Map section▼
Without map entries, Select returns an empty array. Every field you want must be mapped.
Using item() outside an array context▼
item() only works inside Select. Outside, you'll get errors.
Wrong case in field names▼
JSON is case-sensitive. ID and id are different.
19 — Best practices

Write clean Select actions

  • Map only the fields you need
  • Use clear names on the left side
  • Keep the source untouched
  • Test with real data
  • Document what each Select produces
💡 A clean Select means a clean flow.
